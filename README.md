A one-line joke about working beside an AI coding agent: the agent writes the function, the tests and the commit message, and the human's remaining job is clicking Approve on diffs they have stopped pretending to read. `main.py` (Python 3.13, standard library only, no network, fully deterministic) writes the joke to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```

The joke is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise to `/output/entry.txt`.
